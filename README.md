# Simo

Simo is a privacy-first AI copilot for teachers, built to make everyday classroom work simpler, faster, and more thoughtful.

It helps teachers understand class progress, identify missing work, plan weekly instruction, and draft supportive messages while keeping educators in control of every important decision.

## What Simo does

- Summarizes a class or student group at a glance
- Identifies missing work and follow-up needs
- Helps create weekly planning summaries
- Drafts supportive, teacher-appropriate messages
- Keeps workflows focused on teacher guidance instead of automatic student-facing delivery
- Supports structured, repeatable workflows for common classroom tasks

## Powerful and customizable

Simo is designed to grow with the way teachers work:

- Customizable skills: add, adapt, and organize specialized skills for lesson planning, reporting, student support, classroom analysis, and other workflows.
- Large tool library: access a broad set of tools for files, web research, data processing, scheduling, memory, integrations, and automation.
- Multiple communication channels: use Simo through Telegram and other supported channels so teachers can work from the interface that fits their routine.
- Flexible AI providers: connect the model provider that best fits your needs, including hosted or local setups.
- Shared runtime: keep sessions, tools, memory, and security policies consistent across supported interfaces.
- Extensible architecture: build new skills, tools, workflows, and integrations without changing the core teacher experience.

## Why Simo

Simo is designed for trust and safety in educational settings:

- privacy-first by design
- synthetic demo data for safe prototyping
- teacher-in-the-loop decision making
- draft-only workflows before real-world student communication is sent
- clear boundaries around data access and external actions

## Current status

Simo is currently a prototype and demo project. It is intended for safe testing and experimentation with synthetic data, not for production use with real student records or external messaging automation.
