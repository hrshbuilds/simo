# Simo

Simo is a privacy-first AI copilot for teachers.

It helps teachers quickly understand class progress, identify missing work, plan weekly instruction, and draft supportive messages to students and families. The current demo experience is centered around Telegram, making it easy to interact with the assistant in a familiar, low-friction workflow.

## What Simo does

- Summarizes a class or student group at a glance
- Identifies missing work and follow-up needs
- Helps produce weekly planning summaries
- Drafts supportive, teacher-appropriate messages
- Keeps the workflow focused on teacher guidance rather than automatic student-facing delivery

## Why Simo

Simo is designed for trust and safety in educational settings:

- privacy-first by design
- synthetic demo data for safe prototyping
- teacher-in-the-loop decision making
- draft-only workflows before any real-world student communication is sent

## Current status

Simo is currently a prototype and demo project. It is intended for safe testing and experimentation with synthetic data, not for production use with real student records or external messaging automation.

## Example commands

```text
/overview class-7a
/missing class-7a
/report class-7a
/draft student-003 in class-7a
```

## Project goal

Simo aims to give teachers a practical AI assistant for classroom operations while keeping human oversight, privacy boundaries, and responsible use at the center of the experience.
